# AI 에이전트에게 전달할 첫 작업

이 저장소의 AGENTS.md, CLAUDE.md, docs/SAJUENGINE_SERVICE_GUIDE.md와 설치된 sajuengine의 README 및 공개 타입을 읽어라. 엔진 패키지는 수정하지 않는다.

첫 상품은 원국 중심의 짧은 종합 사주 풀이로 만든다. 성향, 강점, 일, 돈, 연애, 사람 관계를 포함한다. 사용자 출생정보를 받아 sajuengine을 서버에서 실행하고, 상품별 해석을 앱의 규칙으로 정리한 다음 캐릭터 메시지로 보여준다.

다음 순서로 구현하라.

1. 설치된 패키지와 examples의 실행을 확인한다.
2. 입력 검증, 요청 안의 계산 재사용, 구조화된 질문을 연결한다.
3. 계산된 사실, 채택한 해석, 사용자 상황, 창작 장면을 구분하는 앱 데이터 형식을 만든다.
4. 성향 등 기존 내장 근거로 설명 가능한 범위부터 연결한다. 새 규칙은 적용 조건과 반대·보류 조건, 출처와 버전, 테스트를 함께 작성한다. AI 초안 규칙을 전문가 검토 완료로 표시하지 않는다.
5. 처음에는 Mock 생성기로 캐릭터 말풍선을 만들어, 작성 중 표시와 주제별 진행을 갖춘 메신저 화면을 완성한다.
6. 생성 상태, 완성된 결과, 읽은 위치를 저장하고 다시 열 때 같은 결과를 보여준다.
7. 선택한 LLM 제공자를 교체 가능한 앱 함수 뒤에 연결한다. 실제 키는 서버 환경에서만 읽고, 필요한 변수 이름과 모델 선택 방법을 설명한다. 설정되지 않은 실 호출을 임의로 실행하지 않는다.
8. 형식, 근거 참조, 계산값, 대상과 기간, 창작 구분만 우선 검사한다. 말투 검사를 과도하게 늘리거나 원본 앱의 모든 검사기를 옮기지 않는다.
9. 알려진 시각, 시각 미상, 근거 부족, 생성 실패, 저장 결과 다시 보기를 검증한다.

현재 저장소의 프레임워크 버전과 파일 구조를 확인해 구현한다. 설치 절차가 끝났다면 새 프로젝트를 또 생성하지 않는다. 로그인·결제·자유 질문 상담·장편 PDF는 첫 상품 완료 후 별도 작업으로 둔다. 결과 보고에는 실제 LLM 실행 여부와 새 환경 변수를 포함하라.
