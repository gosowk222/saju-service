# 상품 정의 예시

이 파일은 앱이 정하는 상품 명세의 예다. sajuengine의 공식 입력 형식이 아니며, 상품 이름과 분량은 제작자가 바꾼다.

## 상품

- 상품 ID와 버전: `starter-overview`, `1.0.0`
- 목적: 원국의 여러 주제를 짧게 이해하고 한 캐릭터에게 상담받는 느낌을 제공한다.
- 표현: 메신저, 친근한 존댓말, 주제별 순차 출력.
- 입력: 출생 날짜·시각 정확도·장소·달력 기준. 직업과 고민은 선택 입력.
- 시각 미상: 없는 시주를 채우지 않고 확보된 재료만 사용한다.
- 창작: 주제별 짧은 일상 장면을 선택적으로 허용한다. 과거 사건과 사용자 상황은 만들어내지 않는다.

## 주제

| 앱 주제 ID | 질문 | inquiry 분야 | 기본 범위 |
| --- | --- | --- | --- |
| temperament | 나는 어떤 방식으로 반응하는가 | temperament | natal |
| strengths | 어떤 힘을 자주 쓰는가 | strengths | natal |
| work | 어떻게 일하는 편인가 | career | natal |
| money | 돈을 어떤 관점에서 다루는가 | wealth | natal |
| romance | 관계에서 무엇을 중시하는가 | romance | natal |
| people | 사람들과 어떤 방식으로 지내는가 | social | natal |

실제 기능 정의의 M03 `topics`에도 이 상품이 사용할 여섯 분야를 넣는다. 제공한 최소 실행 예제는 세 분야만 계산하므로 첫 상품에 맞게 늘린다. 결과에 없는 결론은 목차를 채우기 위해 만들지 않는다.

## 주제별 작성 계획

각 주제에 핵심 해석, supporting 결론, 반대 근거, 사용자 상황, 이미 다른 주제에서 설명한 내용, 창작 허용 범위, 목표 메시지 개수를 기록한다. 메시지 개수는 UI 목표이며 엔진 설정이 아니다.

## 저장과 다시 보기

상품·규칙·캐릭터 버전, 원본 결과 참조, 주제별 작성 계획, 생성된 메시지, 읽은 위치를 저장한다. 재방문은 저장한 결과를 보여준다. 새로운 날짜로 다시 계산하는 상품은 별도 생성 건으로 관리한다.

## 첫 출시 전 확인

가상 입력으로 알려진 시각과 시각 미상을 확인한다. 해석이 없는 주제의 표시, 생성 실패, 저장 결과 다시 보기, 말풍선의 읽기 흐름을 확인한다. LLM을 실제 호출한 결과를 읽어 말투와 반복을 점검하며 그 실행 여부를 기록한다.
