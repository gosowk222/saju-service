# 디자인 시스템 적용 메모

값의 기준은 `saju-design-system/tokens.css`이고, `src/app/globals.css`에서 Tailwind 클래스와 연결한다. Tailwind의 기본 색·간격·글자 크기는 토큰과 달라서 모두 지웠다. `p-4`는 토큰의 12px이고 Tailwind 기본값 16px이 아니다.

## 문서 간 차이의 처리

| 항목 | 문서 내용 | 적용 |
| --- | --- | --- |
| 보드 파일 이름 | `.dc.html`로 표기 | 실제 파일인 `.html` 사용 |
| 명식 표의 십성 라벨 | 10px | 금지 규칙과 토큰에 맞춰 `caption-sm` 11px 사용 |
| 로그인 보드 | 소셜 4종(카카오·Google·Apple·이메일) | 디자인 시스템의 소셜 로그인은 범용 컴포넌트 예시다. 이 앱의 실제 로그인 정책은 카카오만이라(출시 버전까지, `docs/AUTH_POLICY.md`) "카카오로 시작하기" 버튼 하나만 둔다. 카카오 고정색과 52px·radius 12 규격은 그대로 |
| 하단 탭 | 홈·탐색·보관함·마이 4개 고정 | 그대로 구현. 탐색은 상품 목록, 마이는 계정, 무료 이용권, 로그아웃만 제공 |
| 보드의 후기, 구매 수 | 예시 데이터 | 구현하지 않음 |
| 마이 보드의 이용권 카드(`primary` 바탕, 골드 코인, 충전하기) | 유료 이용권 예시 | 충전·묶음 구매는 만들지 않는다. 무료 테스트의 무료 이용권 한 장만 기존 `Card`와 `Badge`(무료 = `green`)로 보여 준다 (`src/components/free-ticket-card.tsx`). 홈에서는 상품 카드 아래에 두어 늦게 그려져도 상품 카드가 밀리지 않게 했다 |
| 상품 상세 결제 바 | 가격 + 정가 취소선 + 할인율 | 무료 테스트 모드에서는 정가(990원)에 취소선(`gray-500` 400)을 긋고 "무료 이용권 1장" 배지(`green`)를 둔다. 상품의 가격 설정은 바꾸지 않았다 |
| 포스터 일러스트 | 이미지 자리 | 첫 상품은 묘묘 그림을 쓴다 (아래 "상품 그림"). 그림이 오기 전과 그림이 없는 상품은 `primary-900` 면 |
| 상품 상세 히어로 | 16:10, 화면 위 풀폭, 뒤로·찜·공유 아이콘을 그림 위에 둠 | 16:10 풀폭은 보드대로 적용. 흰 머리글(뒤로, 상품 이름)은 기존대로 두고 찜·공유는 만들지 않음 |
| 보관함 썸네일 | 64px, radius 12 | 기존 칸 크기 56px(`size-tile`)를 유지하고 모양만 `radius-md` |

## 토큰 밖의 값

| 값 | 위치 | 이유 |
| --- | --- | --- |
| Tailwind 기본 유틸리티의 작은 크기 (`h-1`, `h-4`, `h-5`, `h-6`, `h-7`, `w-7`, `h-9`) | 진행 막대, 체크박스, 아바타, 배지, 스켈레톤 줄 | 토큰의 간격 단계를 사용. `h-4`는 12px, `h-5`는 16px, `h-6`은 20px, `h-7`은 24px, `h-9`는 40px |
| `max-w-[85%]` | 말풍선 | 비율 값은 일반 배치 설정 |
| `aspect-3/4`, `aspect-16/10` | 포스터, 상품 상세 히어로 | 디자인 시스템의 포스터 3:4, 상품 상세 16:10 |
| `max-w-[42%]`, `max-w-[5em]` | 상품 상세 히어로의 부설명과 제목 | 일반 배치 설정. 부설명은 폭의 42%, 제목은 한 줄 다섯 글자 정도에서 줄을 바꿔 배너의 빈 왼쪽 안에 둔다 |
| `--breakpoint-desktop: 768px` | `globals.css` | tokens.json `layout.breakpoints.desktop`. 미디어 쿼리에는 CSS 변수를 쓸 수 없어 값을 옮겨 적었다. 히어로 글자를 키울 때만 쓴다 |

## 상품 그림과 캐릭터 프로필

그림은 `public/images/`에 원본 PNG 그대로 두고 `next/image`로 그린다. 브라우저에는 화면 크기에 맞춘 WebP가 간다 (투명 배경 유지). 경로와 원본 크기는 설정 한곳에만 적는다.

| 그림 | 파일 | 설정 | 쓰는 화면 |
| --- | --- | --- | --- |
| 묘묘 프로필 (1:1, 투명 배경) | `public/images/personas/myomyo-profile.png` | `src/domain/personas/index.ts`의 `avatar` | 메신저 아바타와 머리글, 맛보기, 상품 상세의 캐릭터 소개와 예시, 로그인 |
| 상품 배너 (16:10) | `public/images/products/first-overview-banner.png` | `src/domain/products/first-overview.ts`의 `art.banner` | 상품 상세 히어로 |
| 상품 포스터 (3:4) | `public/images/products/first-overview-poster.png` | 같은 파일의 `art.poster` | 홈과 탐색의 포스터 카드, 보관함 썸네일 |

- 상품명과 부설명은 그림에 넣지 않고 화면 글자로 올린다. 포스터는 아래쪽 여백, 배너는 왼쪽 여백에 둔다. 스크림과 글자색은 디자인 시스템 규칙(`bg-scrim`, 흰 제목, 72% 흰 부제)을 따른다.
- 작은 원형 아바타와 보관함 썸네일은 그림의 일부(`square`)만 보여 준다. 아바타는 가운데 80%, 썸네일은 포스터의 얼굴과 머리핀 부분이다 (`src/components/ui/art.tsx`).
- 옆에 이름 글자가 있는 아바타·포스터·썸네일은 장식용(`alt=""`)이고, 상품 상세 배너만 그림 설명을 읽어 준다.
- 화면 확인은 `tests/e2e/visual.spec.ts`가 한다. 그림 요청 실패, 비율, 글자가 얼굴과 소품을 가리는지, 로딩 중 흔들림, 투명 배경을 보고 스크린샷을 `test-results/visual/`에 남긴다.

## 불러오는 중 화면

- 그림 자리: 그림이 오기 전에는 같은 비율의 면이 자리를 잡는다. 포스터·배너·썸네일은 `primary-900`(디자인 시스템의 포스터 자리 색), 원형 아바타는 `primary-100`. 포스터 위 글자는 그림보다 먼저 보인다.
- 화면 전체: 상품 상세와 보관함은 실제 화면과 같은 모양의 스켈레톤(`gray-100` 면, 배너 자리는 `primary-900`)을 보여 준다. 다른 화면은 기존 로딩 표시(입력 중 점 세 개)를 쓴다.
- 스켈레톤은 움직이지 않는다. 디자인 시스템이 마키·무한 반복 효과를 금지하기 때문이다. 입력 중 표시는 이미 예외로 둔 반복 효과다.
- 첫 화면에 보이는 포스터는 바로 불러온다(`loading="eager"`). 그림에 페이드인을 넣지 않은 이유: 그림이 투명한 동안은 LCP로 잡히지 않아, 스크립트가 붙을 때까지 첫 화면 표시가 늦어진다.

## 추가로 필요할 수 있는 토큰

- 카카오 라벨은 공식 지침이 검정 85%이고 디자인 시스템이 `#191600`이다. 디자인 시스템 토큰을 썼다.
