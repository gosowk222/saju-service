# 디자인 시스템 적용 메모

값의 기준은 `saju-design-system/tokens.css`이고, `src/app/globals.css`에서 Tailwind 클래스와 연결한다. Tailwind의 기본 색·간격·글자 크기는 토큰과 달라서 모두 지웠다. `p-4`는 토큰의 12px이고 Tailwind 기본값 16px이 아니다.

## 문서 간 차이의 처리

| 항목 | 문서 내용 | 적용 |
| --- | --- | --- |
| 보드 파일 이름 | `.dc.html`로 표기 | 실제 파일인 `.html` 사용 |
| 명식 표의 십성 라벨 | 10px | 금지 규칙과 토큰에 맞춰 `caption-sm` 11px 사용 |
| 로그인 보드 | 소셜 4종(카카오·Google·Apple·이메일) | 디자인 시스템의 소셜 로그인은 범용 컴포넌트 예시다. 이 앱의 실제 로그인 정책은 카카오만이라(출시 버전까지, `docs/AUTH_POLICY.md`) "카카오로 시작하기" 버튼 하나만 둔다. 카카오 고정색과 52px·radius 12 규격은 그대로 |
| 하단 탭 | 홈·탐색·보관함·마이 4개 고정 | 그대로 구현. 탐색은 상품 목록, 마이는 계정, 무료 이용권, 로그아웃만 제공 |
| 보드의 후기, 구매 수 | 예시 데이터 | 구현하지 않음 |
| 마이 보드의 이용권 카드(`primary` 바탕, 골드 코인, 충전하기) | 유료 이용권 예시 | 충전·묶음 구매는 만들지 않는다. 무료 테스트의 무료 이용권 한 장만 기존 `Card`와 `Badge`(무료 = `green`)로 보여 준다 (`src/components/free-ticket-card.tsx`). 홈에서는 상품 카드 아래에 두어 늦게 그려져도 상품 카드가 밀리지 않게 했다 |
| 상품 상세 결제 바 | 가격 + 정가 취소선 + 할인율 | 무료 테스트 모드에서는 정가(990원)에 취소선(`gray-500` 400)을 긋고 "무료 이용권 1장" 배지(`green`)를 둔다. 상품의 가격 설정은 바꾸지 않았다 |
| 포스터 일러스트 | 이미지 자리 | 첫 상품은 묘묘 그림을 쓴다 (아래 "상품 그림"). 그림이 오기 전과 그림이 없는 상품은 `primary-900` 면 |
| 상품 상세 히어로 | 16:10, 화면 위 풀폭, 뒤로·찜·공유 아이콘을 그림 위에 둠 | 16:10 풀폭은 보드대로 적용. 흰 머리글(뒤로, 상품 이름)은 기존대로 두고 찜·공유는 만들지 않음 |
| 보관함 썸네일 | 64px, radius 12 | 기존 칸 크기 56px(`size-tile`)를 유지하고 모양만 `radius-md` |
| 상품 상세 히어로 (그림 속 글자가 있는 상품) | 16:10 칸 위에 HTML 제목·부설명 | 무진 배너(1672×941, 약 16:9)는 그림 안에 상품 이름과 문구가 있어 원본 비율 그대로 화면 폭에 맞추고 글자·스크림을 겹치지 않는다. 제목은 화면 읽기용 `h1`(sr-only), 그림 속 문구는 그림 설명(alt)이 읽는다. 묘묘는 기존 16:10 그대로 (`art.textInImage`) |
| 포스터 카드 (그림 속 글자가 있는 상품) | 스크림 + 흰 Serif 제목 | 무진 포스터는 그림 위에 스크림과 제목을 올리지 않고 화면 읽기용 제목(`h2`, sr-only)만 둔다. 카드 아래 상품 이름·가격은 그대로 |
| 상품 상세 불러오는 중 | 16:10 배너 자리 | 화면이 상품을 알기 전에 그리는 공통 스켈레톤이라 16:10을 유지한다. 무진 배너는 조금 낮아(16:9) 그림이 올 때 아래 내용이 약간 올라간다 |
| 무진 장 제목 | (보드 없음) | 중간 크기 Serif 제목 토큰이 없어 `type-h2`(Sans 24/32)를 쓴다. 족자 제목(풀이 이름)만 `type-h1`(Serif 32) |
| 무진 목차 | 사이드 내비 없음 | 머리글 오른쪽의 목차 버튼으로 바텀시트(위 모서리 `radius-xl`, `shadow-float`, 올라오는 길이 `duration-slow`)를 연다. 현재 읽는 칸은 하단 탭처럼 굵기 600과 `aria-current`로 표시 |
| 무진 상품 상세 | 상품 상세 보드에는 상담 장면이 없음. 무진 명세 03 1절은 '상품 상세 첫 진입부터 상담 장면' | 배너 바로 아래 첫 칸에 입력 화면과 같은 상담 장면(정지 그림, 밤 히어로 면)과 무진의 첫 인사(`lines.intake.greet`)를 둔다. 하단 결제 바의 버튼은 '무진과 상담 시작하기'(대화형 입력으로 이동, 로그인이 필요하면 기존처럼 로그인을 거친다). 화면 읽기용 제목, 상품 정보(칸 목록·구성·가격·캐릭터 소개)는 그대로. 묘묘 상세는 그대로 |

## 토큰 밖의 값

| 값 | 위치 | 이유 |
| --- | --- | --- |
| Tailwind 기본 유틸리티의 작은 크기 (`h-1`, `h-4`, `h-5`, `h-6`, `h-7`, `w-7`, `h-9`) | 진행 막대, 체크박스, 아바타, 배지, 스켈레톤 줄 | 토큰의 간격 단계를 사용. `h-4`는 12px, `h-5`는 16px, `h-6`은 20px, `h-7`은 24px, `h-9`는 40px |
| `max-w-[85%]` | 말풍선 | 비율 값은 일반 배치 설정 |
| `aspect-3/4`, `aspect-16/10` | 포스터, 상품 상세 히어로 | 디자인 시스템의 포스터 3:4, 상품 상세 16:10 |
| `aspect-16/9` | 무진 상담 장면의 영상 자리 (`src/components/mujin/scene.tsx`) | B02~B04 영상(16:9)이 메타데이터를 받기 전에도 같은 높이를 잡아 정지 그림에서 영상으로 바뀔 때 장면이 흔들리지 않게 한다. Tailwind의 `aspect-video`는 테마 변수(`--aspect-video`)로 만들어지는데 `globals.css`가 테마 값을 모두 지워(`--*: initial`) CSS가 생기지 않는다. 분수 값은 테마 없이 만들어진다 (`@tailwindcss/node`로 `globals.css`를 컴파일해 `aspect-video`는 규칙 없음, `aspect-16/9`는 `aspect-ratio: 16/9` 생성을 확인, 2026-11-12). 같은 이유로 테마 이름을 쓰는 비율·그림자 클래스(`aspect-video`, `shadow-md` 등)는 쓰지 않는다 |
| `max-w-[42%]`, `max-w-[5em]` | 상품 상세 히어로의 부설명과 제목 | 일반 배치 설정. 부설명은 폭의 42%, 제목은 한 줄 다섯 글자 정도에서 줄을 바꿔 배너의 빈 왼쪽 안에 둔다 |
| `--breakpoint-desktop: 768px` | `globals.css` | tokens.json `layout.breakpoints.desktop`. 미디어 쿼리에는 CSS 변수를 쓸 수 없어 값을 옮겨 적었다. 히어로 글자를 키울 때만 쓴다 |
| `h-11 w-11` (120px) | 무진 상담 장면의 얼굴 그림 | 간격 토큰 `space-11`(120px). 장면 그림(B01)이 오기 전 임시 크기 |
| `w-9`, `h-7` | 무진 목차·상품 상세의 장 번호 알약 | 간격 토큰(40px, 24px). '10장', '기초', '정리' 두세 글자가 한 줄에 들어가는 폭 |
| `scroll-mb-11` | 무진 입력칸, 후속 질문 입력칸 | 포커스로 화면이 움직일 때 아래 고정 버튼 줄에 가리지 않도록 120px(`space-11`) 여유를 둔다 |
| `scale(1.6)`, `scale(0.96)`, `translateY(100%)` | `globals.css`의 `paper-lift`, `scroll-unfurl`, `sheet-in` | 움직임의 크기 비율이다. 길이·곡선은 토큰(`duration-slow`, `ease-standard`), 이동 거리는 간격 토큰(`space-7`, `space-8`)을 쓴다 |
| 오행 분포 막대의 조각 길이 (`flex-grow` 인라인 값) | 무진 오행 분석 표 | 실제 세력 비율 값으로 정해지는 데이터 값이다. 막대 높이 12px(`space-4`), 조각 사이 2px(`space-1`)는 컴포넌트 보드의 분포 바와 같다 |
| `max-w-[85%]` | 무진 후속 질문 말풍선 | 메신저 말풍선과 같은 비율 값 |
| 읽는 칸을 찾는 화면 띠 (`rootMargin` 위쪽 머리글 높이, 아래쪽 65%) | 무진 목차의 현재 위치 | 머리글 높이는 `--size-header` 토큰을 읽어 쓴다. 65%는 화면 위쪽 약 1/3에 들어온 첫 칸을 현재 칸으로 보는 배치 값 |

## 상품 그림과 캐릭터 프로필

그림은 `public/images/`에 원본 PNG 그대로 두고 `next/image`로 그린다. 브라우저에는 화면 크기에 맞춘 WebP가 간다 (투명 배경 유지). 경로와 원본 크기는 설정 한곳에만 적는다.

| 그림 | 파일 | 설정 | 쓰는 화면 |
| --- | --- | --- | --- |

| 상품 포스터 (3:4) | `public/images/products/first-overview-poster.png` | 같은 파일의 `art.poster` | 홈과 탐색의 포스터 카드, 보관함 썸네일 |
| 무진 상품 배너 (1672×941, 글자 포함) | `public/images/products/mujin-banner-landscape.png` | `src/domain/products/mujin-overview.ts`의 `art.banner` | 상품 상세 히어로 (원본 비율, 글자 겹침 없음) |
| 무진 상품 포스터 (3:4, 글자 포함) | `public/images/products/mujin-poster-portrait.png` | 같은 파일의 `art.poster` | 홈과 탐색의 포스터 카드(글자 겹침 없음), 보관함 썸네일(얼굴 부분) |
| 무진 프로필·상담 장면 (임시, 설정화 얼굴 크롭) | `public/images/personas/mujin-character-sheet.png` | `src/domain/personas/index.ts`의 무진 `avatar` | 원형 아바타, 무진 상품 상세·입력·족자 화면의 상담 장면(120px). B01·B05를 받으면 바꾼다 |

- 상품명과 부설명은 그림에 넣지 않고 화면 글자로 올린다. 포스터는 아래쪽 여백, 배너는 왼쪽 여백에 둔다. 스크림과 글자색은 디자인 시스템 규칙(`bg-scrim`, 흰 제목, 72% 흰 부제)을 따른다.
- 예외: 그림 안에 상품 이름과 문구가 이미 있는 상품(무진, `art.textInImage`)은 그림 위에 글자와 스크림을 올리지 않는다. 화면 읽기용 제목만 숨겨 두고, 그림 속 문구는 그림 설명(alt)이 읽는다. 보관함 썸네일은 잘린 그림이라 alt를 비운다.
- 작은 원형 아바타와 보관함 썸네일은 그림의 일부(`square`)만 보여 준다. 아바타는 가운데 80%, 썸네일은 포스터의 얼굴과 머리핀 부분이다 (`src/components/ui/art.tsx`).
- 옆에 이름 글자가 있는 아바타·포스터·썸네일은 장식용(`alt=""`)이고, 상품 상세 배너만 그림 설명을 읽어 준다.
- 화면 확인은 `tests/e2e/visual.spec.ts`가 한다. 그림 요청 실패, 비율, 글자가 얼굴과 소품을 가리는지, 로딩 중 흔들림, 투명 배경을 보고 스크린샷을 `test-results/visual/`에 남긴다.

## 불러오는 중 화면

- 그림 자리: 그림이 오기 전에는 같은 비율의 면이 자리를 잡는다. 포스터·배너·썸네일은 `primary-900`(디자인 시스템의 포스터 자리 색), 원형 아바타는 `primary-100`. 포스터 위 글자는 그림보다 먼저 보인다.
- 화면 전체: 상품 상세와 보관함은 실제 화면과 같은 모양의 스켈레톤(`gray-100` 면, 배너 자리는 `primary-900`)을 보여 준다. 다른 화면은 기존 로딩 표시(입력 중 점 세 개)를 쓴다.
- 스켈레톤은 움직이지 않는다. 디자인 시스템이 마키·무한 반복 효과를 금지하기 때문이다. 입력 중 표시는 이미 예외로 둔 반복 효과다.
- 첫 화면에 보이는 포스터는 바로 불러온다(`loading="eager"`). 그림에 페이드인을 넣지 않은 이유: 그림이 투명한 동안은 LCP로 잡히지 않아, 스크립트가 붙을 때까지 첫 화면 표시가 늦어진다.

## 무진의 종합 사주 화면 (족자 상품)

대화형 입력(`src/components/mujin/intake.tsx`)과 족자 보고서(`src/components/mujin/scroll-reading.tsx`)는 새 디자인 값 없이 기존 토큰과 컴포넌트로 만들었다. 보드에 없는 화면이라 아래처럼 정했다.

- 상담 장면: 밤 히어로 면(`primary-900`, `radius-xl`) 위에 얼굴 그림, 이름, 상태 배지, 무진의 말풍선(풀이 말풍선 `gray-100`)을 둔다. 책상 위 종이는 흰 면(`radius-sm`)과 `gray-700` 선이다. B01~B04 그림·영상이 없어 쓰는 임시 장면이며 최종 아트가 아니다. 영상 자리(소리 없음, 화면 안 재생, 정지 그림 대체, 움직임 줄이기·숨긴 탭에서 멈춤)는 구조만 있다.
- 종이→족자 전환(B06): 첫 무료 칸이 완성되면 책상 위 종이가 커지며 사라지고(`paper-lift`) 그 아래에서 족자가 펼쳐진다(`scroll-unfurl`). 둘 다 `duration-slow`(300ms) 한 번이라 디자인 시스템의 300ms 상한 안이다. 움직임을 줄이는 설정에서는 토큰이 0ms가 되어 바로 보인다. 다시 열면 연출 없이 바로 보인다.
- 족자: 위아래 축은 `primary-900` 띠(`h-3`, `radius-full`), 종이는 흰 면과 `gray-200` 세로 테두리다. 본문은 `type-body-lg`(17/26), 보조 상자는 `type-body`(15/22), 핵심 답은 `primary-50` 면이다. 가정해 보는 장면은 메신저 장면처럼 제목 없이 `primary-50` 면과 왼쪽 `primary-300` 선으로만 구분한다 (화면 읽기 프로그램에만 '가정해 보는 장면'이라고 알린다). 왼쪽 선은 1px(`border-l`)이다. 디자인 시스템은 면을 1px 테두리로 나누고 2px는 포커스·일간 강조·선택된 가격 라디오에만 쓰는데, 장면 선은 강조가 아니라 구분 표시이고 면 색(`primary-50`)이 이미 장면을 알리기 때문이다 (처음 구현의 2px `border-l-2`를 2026-11-12에 1px로 맞췄다).
- 칸 상태: 잠김·대기는 `neutral` 배지, 작성 중은 `progress` 배지와 움직이지 않는 스켈레톤(`gray-100`), 오류는 `danger` 배지와 다시 시도 버튼, 완료는 `neutral`(디자인 시스템의 완료 배지) 배지다. 잠긴 칸은 스켈레톤을 쓰지 않고 자물쇠 아이콘과 설명·질문 목록만 보여 준다.
- 실패 안내: 오류 칸은 `danger` 안내(실패 이유 + 할 수 있는 일)와 보조 버튼 '다시 시도하기'다. 다시 시도할 수 없으면 버튼 없이 횟수를 다 썼다는 안내와 문의 안내만 둔다(설정 오류는 횟수를 말하지 않는다). 단계가 실패했는데 오류 칸이 없으면 같은 `danger` 안내와 버튼을 상담 장면 아래(족자 위)에 둔다. 이 화면이 스스로 멈춘 이유는 `warning` 안내다. 상담 장면 배지는 다시 시도할 수 있으면 '다시 시도 필요', 없으면 '문의 필요'(`neutral`)다. 새 디자인 값은 없다.
- 표: 칸은 `gray-200`·`gray-100` 선, 머리는 `type-caption-sm`, 값은 `type-label`, 숫자는 `tabular-nums`. 좁은 화면에서 넘치는 표는 가로로 밀어 보는 영역(키보드로도 밀 수 있게 포커스를 받는다)에 둔다. 오행 칸은 오행 틴트, 12개월 표의 표지 구성은 긍정 `green`, 주의 `gold`, 함께 `primary` 틴트에 글자를 함께 쓴다. 점수·확률 그래프는 그리지 않는다.
- 이용권·결제 안내, 후속 질문, PDF 카드는 기존 버튼·카드 규격을 그대로 쓴다. 연결이 끊겼다는 안내는 토스트 규격(`gray-800` 면, 흰 글자, `radius-md`)으로 화면 아래에 둔다.

### 추가로 필요할 수 있는 토큰 (무진)

| --- | --- | --- |
