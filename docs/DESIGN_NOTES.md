# 디자인 시스템 적용 메모

값의 기준은 `saju-design-system/tokens.css`이고, `src/app/globals.css`에서 Tailwind 클래스와 연결한다. Tailwind의 기본 색·간격·글자 크기는 토큰과 달라서 모두 지웠다. `p-4`는 토큰의 12px이고 Tailwind 기본값 16px이 아니다.

## 문서 간 차이의 처리

| 항목 | 문서 내용 | 적용 |
| --- | --- | --- |
| 보드 파일 이름 | `.dc.html`로 표기 | 실제 파일인 `.html` 사용 |
| 명식 표의 십성 라벨 | 10px | 금지 규칙과 토큰에 맞춰 `caption-sm` 11px 사용 |
| 로그인 보드 | 이메일, Apple 버튼 포함 | 요구사항에 따라 카카오·구글만 구현 |
| 하단 탭 | 홈·탐색·보관함·마이 4개 고정 | 그대로 구현. 탐색은 상품 목록, 마이는 계정과 로그아웃만 제공 |
| 보드의 후기, 구매 수, 이용권 | 예시 데이터 | 구현하지 않음 |
| 포스터 일러스트 | 이미지 자리 | 일러스트가 없어 `primary-900` 단색 면으로 대체 |

## 토큰 밖의 값

| 값 | 위치 | 이유 |
| --- | --- | --- |
| Google 버튼 `#747775`, `#1F1F1F`, 로고 색 | `globals.css`, `login-buttons.tsx` | Google 공식 표기 지침의 고정 값. 카카오 고정색과 같은 성격이고 토큰에 없음 |
| Tailwind 기본 유틸리티의 작은 크기 (`h-1`, `h-5`, `h-7`, `w-7`, `h-9`) | 진행 막대, 체크박스, 아바타, 배지 | 토큰의 간격 단계를 사용. `h-5`는 16px, `h-7`은 24px, `h-9`는 40px |
| `max-w-[85%]` | 말풍선 | 비율 값은 일반 배치 설정 |
| `aspect-[3/4]`, `aspect-[4/3]` | 포스터 | 토큰의 포스터 비율 3:4 |

## 추가로 필요할 수 있는 토큰

- 포스터 일러스트 자산. 현재는 단색 면이다.
- 카카오 라벨은 공식 지침이 검정 85%이고 디자인 시스템이 `#191600`이다. 디자인 시스템 토큰을 썼다.
