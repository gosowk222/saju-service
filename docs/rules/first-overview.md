# 첫 상품 규칙 (first-overview 3.1.0)

코드: `src/domain/rules/` (`first-overview.ts` 원국 규칙, `life.ts` 생활 주제·에너지·투자 규칙, `timing.ts` 기간 규칙, `natal-tables.ts`·`life-tables.ts` 해석 문장, `materials.ts` 재료 읽기, `drafting.ts` 결론 초안 도우미). 작성 계획은 `src/domain/reading/plan.ts`, 질문 반영은 `focus.ts`.

**검토 상태: 모두 `unreviewed`.** AI가 작성한 초안이며 명리 전문가의 검토를 받지 않았다. 사람이 실제로 검토하기 전에는 `human-reviewed`로 바꾸지 않는다. 출시 전 명리 전문가의 검토를 권장한다.

**채택한 해석 관점:** 십성 계열(비겁·식상·재성·관성·인성)의 비중, 일간 강약, 격국, 일지(배우자 자리)의 본기 십성, 원국과 기간의 합·충·형, 일부 신살을 쓰는 일반적인 자평 계열의 생활 해석을 서비스가 쉬운 말로 옮긴 것이다. 궁통보감 조후 처방이나 고전 원문은 이 상품의 규칙에 쓰지 않는다. 서로 다른 관점을 섞지 않기 위해서다.

## 공통

- 근거: 계산값은 공개 필드(`assessment`, `natalFacts.positions[].tenGod`, `evidence`의 `kind`·`ruleId`·`tags`·`periodId`)로만 읽는다. `assertion` 문장은 읽지 않는다.
- 직접 근거(supporting)는 `m01.assessment.families`·`strength`·`pattern` 판단, 원국 관계(`m02.*`)·신살·M03 관측 판단의 ID다. 일지 십성은 M01 계열 분포에 포함된 값이라 계열 분포 판단을 근거로 연결한다.
- 반대 근거(counter): 그 주제의 M03 `review-required` 판단은 모든 결론에 반대 근거로 연결하고 "단정하지 않고 경향으로 전달"한다는 한계를 붙인다. 주제별 반대 근거는 아래에 있다.
- 보류(deferred): 시주를 모르고(`coverage` ≠ complete) 판단 기준값과 ±3~5 이내라 시주를 알면 판단이 바뀔 수 있을 때. 시주를 몰라 관측된 기둥에서만 안 보이는 계열은 없다고 단정하지 않는다.
- 결론이 없으면 지어내지 않는다. 기준을 만족하는 재료가 없으면 그 항목은 결론을 내지 않고, 상품 화면에서는 그 항목을 다루지 않는다.
- 모든 결론의 한계: "성향을 읽는 해석이며 실제 사건, 금액, 합격 여부를 판단하지 않는다."
- 신살 결론의 한계: "신살은 전통 해석의 보조 표지이며 단독으로 능력이나 사건을 확정하지 않는다."
- 생활 주제의 한계는 규칙 8~12에 있다 (가족 짐작, 전통 대응표, 진단 아님, 종목 판단 아님).
- 약점: 근거가 있는 결론만 `weakness`(무엇이·언제·잃는 것·바꿀 점)를 갖는다. LLM은 weakness가 없는 결론에 약점을 붙이지 않는다.

| 보조 맥락 | 그 달을 덮는 세운·대운의 period 근거를 `contextualEvidenceIds`로 연결 (직접 근거 아님) |

| 연애의 인연 표지 | 전통 관법의 성별 기준(여성 사주는 관성, 남성 사주는 재성)을 "전통 관법에서 이성 인연과 연결해 읽는 기운"으로 표시한다. 성별을 모르면 인연 표지로 보지 않는다 |

| 판단 | 긍정만 → candidate(힘을 실어 볼 때) / 긍정과 조심 → deferred(섞인 때), 조심 표지를 반대 근거로 / 조심만 → observation(점검할 때) / 중립만 → observation |
| 달 고르기 | 상품 내부 선택 기준 = 긍정 표지 수 − 조심 표지 수. 같은 표지는 한 번만 센다. 사건 확률이 아니다. 주목할 달은 점수 1 이상 상위 3개(동점이면 빠른 달), 조심할 달은 조심 우세 2개 |
| 한계 | "전통 해석상 주목할 활동 기간이며 합격, 만남, 수입 같은 사건이 생긴다는 뜻이 아니다", 절기 기준 월이라 달력 1일과 경계가 다르다, 대운 경계는 근사값 |
| 보류 | 표지가 없으면 결론 없음. 분석 기간 안에 결론이 없으면 `insufficient`로 남기고 "살펴본 기간 안에 직접 연결되는 표지를 찾지 못했다"고 말한다 |

## 명리 설명 재료 (3.1.0, `src/domain/reading/lore.ts`)

판단을 새로 하지 않는다. 규칙 결론이 쓴 근거만 문장으로 옮겨 해석마다 최대 3줄을 붙인다.

| 근거 | 옮긴 문장 예 |
| --- | --- |
| 신살 (근거 ID의 위치) | "시주의 신금(申金)에 천을귀인이 있어요." |
| 합충 (근거 ID의 두 기둥) | "일주의 사화(巳火)와 시주의 신금(申金)이 파(破)·형(刑)·육합(六合) 관계예요." |
| 십성 계열 (근거 문장에 나온 계열의 원국 글자) | "월주의 신금(辛金), 월주의 유금(酉金)은 식신, 시주의 신금(申金)은 상관이에요. 일간 기토(己土)가 생하는(토생금) 금(金) 기운이라 내 기운을 밖으로 풀어내는 자리예요." |
| 일간의 힘 | 태어난 계절(월지)과, 일간과 같은 오행·생해 주는 오행의 비율 합 |
| 격국 | 월지 글자의 십성 |
| 용신 | 용신·희신·기신과 억부·조후 기준 |

- 지지의 십성은 본기 기준이다. 원국에 그 계열 글자가 없으면 "겉으로 드러나 있지 않다"고 쓴다.
- 사실 목록(facts)에 일간을 빗대는 자연물(예: 기토는 기름진 논밭의 흙)과 원국 글자의 오행 개수를 더한다.
- 풀이와 후속 답변에 원국 글자 이름("경금")이나 신살 이름("도화살")이 나오면, 원국과 작성 재료(후속 답변은 이미 전달한 풀이 포함)에 있는지 확인하고 없으면 다시 생성한다 (`check.ts`). 정화·해수·자수·묘목·계수는 일상어와 겹쳐 확인하지 않는다.
