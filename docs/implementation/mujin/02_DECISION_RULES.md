# 무진 02. 판단과 설명 연결

> 이 문서는 사용자가 2026-11-12에 제공한 무진 상품 설계 명세 원문을 옮긴 것이다. 실제 코드와 다른 점과 구현 결정은 [00_START_HERE.md](00_START_HERE.md)에 기록한다.

## 1. 원칙

질문 범위는 다음 45개다.

- 기초 분석 P01~P05.
- 10개 장 × 4개 질문.

45개 질문은 LLM 45회 호출이나 필수 소제목 45개를 의미하지 않는다.

구현 상태를 구분한다.
- 재사용: 기존 조건·예외를 가져오는 것.
- 수정: 기존 판단 중 필요한 부분을 보존하고 잘못된 확장을 제외하는 것.
- 신규 연결: 기존 계산·판단을 새 질문에 연결하는 서비스 코드.

기존 코드의 수치는 현재 구현값이다.
통계적 확률이나 명리학적 감수 완료 기준으로 취급하지 않는다.
실제 감수가 없으면 unreviewed를 유지한다.

먼저 확인할 위치:
- src/server/engine/analyze.ts
- src/server/engine/features.ts
- src/domain/reading/plan.ts
- src/domain/reading/chart.ts
- src/domain/rules/first-overview.ts
- src/domain/rules/natal-tables.ts
- src/domain/rules/life.ts
- src/domain/rules/life-tables.ts
- src/domain/rules/timing.ts

- src/domain/rules/common.ts
- docs/rules/first-overview.md

경로가 달라졌다면 실제 파일을 찾아라.

아래 분기 요약을 사용할 때 실제 코드의 비교 연산자, 괄호, 우선순위, 시주 미상 가드를 함께 확인한다.
요약만 보고 기존 예외 처리를 지우지 않는다.

## 2. 공통 근거 계약

각 판단에는 다음을 추적할 수 있어야 한다.

- 질문 ID.
- 규칙 ID와 버전.
- 채택·조건부·보류 상태.
- 직접 근거와 반대 근거.
- 보조 맥락.
- 원천 자료와 적용 기간.
- 설명 가능한 범위.
- 파생 설명이면 부모 판단과 근거.

새 설명 문장을 새 계산 근거처럼 취급하지 않는다.
같은 원인의 근거를 여러 번 합산하지 않는다.
원국·해당 기간·보조 기간·다른 사람의 근거를 구분한다.

시각 미상에서는 coverage와 기존 경계값 보류 처리를 유지한다.
관측되지 않은 십성을 그 기질의 결핍으로 확정하지 않는다.

## 3. 무료 기초 분석

### P01. 내 원국은 어떻게 구성되는가?

- 실제 계산한 연·월·일·시주와 일간, 제공되는 십성 등의 값을 표시한다.
- 시각 미상은 그대로 표시한다.
- 상태: 계산 재사용·표시 연결.

### P02. 원국 전체에서 무엇을 먼저 읽는가?

- 일간·계절과 실제 채택된 강약·격국 등의 구조를 연결한다.
- 없는 격국·용신을 LLM이 선택하지 않는다.
- 강약을 체력이나 경제적 위험 감수 능력으로 바꾸지 않는다.
- 상태: 재사용·표현 수정.

### P03. 오행 분포는 무엇을 뜻하는가?

- 단순 글자 개수와 엔진의 가중 비율을 구분한다.
- 동률은 공동으로 설명한다.
- 가장 적은 오행을 곧바로 용신·결핍·질병으로 연결하지 않는다.
- 상태: 재사용·표시 수정.

### P04. 원국의 12운성은 어떤 단계인가?

- scope가 natal인 항목을 사용한다.
- basis, position, 간지, 단계를 보존한다.
- 월운 항목을 섞지 않는다.
- 병·사·절을 질병·사망·불운으로 번역하지 않는다.
- 단계의 전통적 의미를 설명하며 사건·길흉을 단독 확정하지 않는다.
- 상태: 신규 표시·해설 연결.

### P05. 십성 구조에서 무엇이 두드러지는가?

- 실제 십성과 5계열 분포, 채택된 중심·보조 조합을 설명한다.
- 실제 가족사나 사건으로 확장하지 않는다.
- 상태: 재사용·편집 연결.

## 4. 1장 성향과 내면

### 1-1. 중요하게 여기는 방향

- 기존 최상위 계열 비중 25% 이상 중심 분기, 그 외 균형 분기 재사용.
- 시주 미상의 상위 두 계열 차이 10%p 이내, 25% 근처 등 기존 보류 조건 유지.
- 상태: 재사용.

### 1-2. 보완하거나 부딪치는 면

- 기존 두 번째 계열 18% 이상 조합 규칙 재사용.
- 시주 미상의 18% 전후 4%p 등 기존 가드 유지.
- 조합이 미채택이면 억지로 이중성을 만들지 않는다.
- 상태: 재사용.

### 1-3. 압박에 대한 반응

- 채택된 강약·중심 성향에 연결된 기존 반응을 조건부 행동으로 설명한다.
- 신약→체력 부족, 신강→경제적 손실 감당 능력 연결은 제외한다.
- 상태: 수정.

### 1-4. 강점이 손해로 바뀌는 조건

- 실제 판단의 upside, weakness, 발생 조건과 기존 조합 설명을 사용한다.
- 없는 약점을 발명하지 않는다.
- 상태: 재사용·설명 연결.

## 5. 2장 재능·적성·배우는 방식

### 2-1. 살릴 수 있는 능력

- 채택된 격국에 기존 PATTERN_ABILITY 대응을 적용한다.
- 격국 미채택이면 해당 능력을 격국 근거로 확정하지 않는다.
- 실제 자격·경력·숙련도를 보유했다고 말하지 않는다.
- 상태: 재사용.

### 2-2. 능력이 드러나는 환경

- 현재 실제 선택 대상인 문창·학당·화개·장성 중 계산된 항목만 사용한다.
- 기존 우선순위로 최대 2개.
- 문서 표에만 있는 신살을 자동 활성화하지 않는다.
- 표지가 없다는 이유로 능력이 없다고 판단하지 않는다.
- 상태: 재사용.

### 2-3. 배우고 연습하는 방법

- 채택 능력·환경에 규칙 작성자가 붙인 의미 태그를 상황별 활동과 연결한다.
- 지능이나 고정 학습 유형을 새로 진단하지 않는다.
- 상태: 신규 연결.

### 2-4. 성과를 막는 조건

- 선택한 능력에 붙은 weakness를 우선 사용한다.
- 기존 최약 계열 12% 이하 보완 행동은 해당 능력과 관련될 때만 보조로 사용한다.
- 시각 미상에서 관측 부재를 결핍으로 확정하지 않는다.
- 상태: 재사용·신규 연결.

## 6. 3장 직업과 사회생활

### 3-1. 역할과 일하는 방식

- 기존 업무 스타일·직업 예시·능력 판단을 연결한다.
- 업종은 활동 예시이며 성공·자격을 보장하지 않는다.
- 상태: 재사용·표현 수정.

### 3-2. 조직과 자율 활동의 조건

- 기존 분기:
  - 관성 20% 이상이고 관성 비중이 비겁 이상이면 조직형.
  - 비겁+식상 50% 이상이고 관성 12% 이하이면 자율형.
  - 그 외 혼합.
- 조직형에서 식상 30% 이상인 예외 등 기존 조건을 유지한다.
- 조직형=취업 정답, 자율형=창업 정답으로 바꾸지 않는다.
- 상태: 재사용.

### 3-3. 취업·프리랜서·사업 비교

- 역할 명확성·자율성·협업·성과 표현을 업무 구조와 책임 조건에 연결한다.
- 강약으로 수입 변동을 견딜 능력을 판정하지 않는다.
- 자금·경험·고객은 사용자 정보가 있을 때만 사용한다.
- 상태: 수정·신규 비교.

### 3-4. 지금 준비할 것

- 질문의 활동과 채택 능력·조건·약점을 연결한다.
- 학생·취업 준비·재직·프리랜서·사업·휴식 모두 다룬다.
- 알 수 없는 현실 조건은 확인할 항목으로 남긴다.
- 상태: 신규 연결.

## 7. 4장 재물과 돈 관리

### 4-1. 돈을 바라보는 방식

- 기존 우선순위:
  - 재성 10% 미만 → 의미 우선.
  - 식상 25% 이상이며 재성 10% 이상 → 결과물·기술 연결.
  - 편재 개수 > 정재 개수 → 기회형.
  - 정재 1개 이상 → 꾸준한 관리형.
  - 미해당 → 미판정.
- 시주 미상에서 관측 부재로 첫 분기를 확정하지 않는다.
- 재성 10%, 식상 25% 전후 3%p 등 실제 가드 유지.
- 재산 규모나 돈의 많고 적음이 아니다.
- 상태: 재사용.

### 4-2. 돈 관리가 흔들리는 조건

- 기존 우선순위:
  - 비겁 25% 이상 → 관계 지출.
  - 관성 20% 이상 → 관리 조건.
  - 인성 25% 이상 → 학습·준비 지출.
  - 그 외 → 구체적 예산 관리 방향.
- 실제 지출 이력으로 단정하지 않는다.
- 상태: 재사용·상황 연결.

### 4-3. 돈과 사람 관계

- 기존 분기:
  비겁 25% 이상·겁재 1개 이상,
  또는 비겁 20% 이상·겁재 2개 이상.
- 비겁 15% 미만의 혼자 부담하는 방향 등 기존 분기도 확인한다.
- 기존 경계 가드를 유지한다.
- 배신·사기·부채 발생으로 확장하지 않는다.
- 상태: 재사용.

### 4-4. 맞는 관리 방식

- 기존 투자 성향의 조건과 우선순위 재사용:
  - 비겁 25% 이상·겁재 1개 이상.
  - 편재>정재이며 식상 또는 재성 20% 이상.
  - 인성 25% 이상.
  - 정재 1개 이상이고 정재≥편재, 또는 관성 20% 이상.
  - 그 외 규칙 관리.
- 실제 코드의 괄호와 우선순위를 확인한다.
- 자산·매매일·수익률 추천이 아니라 관리 습관으로 설명한다.
- 상태: 재사용·표현 수정.

## 8. 5장 연애와 결혼

### 5-1. 마음을 표현하는 방식

- 식상 25% 이상 직접 표현, 12% 이하 은근한 표현, 그 사이 조절형.
- 실제 함지·홍염은 보조로만 사용한다.
- 인기·연애 경험을 확정하지 않는다.
- 상태: 재사용.

### 5-2. 편안한 관계 조건

- 기존 일지 정기 십성 계열의 관계 조건 대응을 사용한다.
- 실제 상대의 외모·직업·성격을 예언하지 않는다.
- 상대 정보가 없으면 두 사람 궁합이라고 부르지 않는다.
- 상태: 재사용·표현 수정.

### 5-3. 가까워질 때 부딪치는 부분

- 실제 일지 관계 표지와 기존 갈등 반응을 연결한다.
- 합과 충이 함께 있으면 둘 다 보존한다.
- 합으로 충이 사라지거나 충이 이별을 확정하지 않는다.
- 상태: 재사용·충돌 처리.

### 5-4. 장기 관계의 합의 조건

- 실제 채택된 자율성·혼자 있는 시간·표현 방식·역할 명확성을 연결한다.
- 돈은 관련 재물 판단이나 사용자 질문이 있을 때 사용한다.
- 배우자·결혼 연도·자녀를 만들지 않는다.
- 상태: 신규 연결.

## 9. 6장 인간관계와 귀인

### 6-1. 관계에서 맡는 역할

- 기존 친구 관계 이미지와 사회 협력 판단을 연결하고 공통 원인을 중복 설명하지 않는다.
- 주변 사람들이 실제로 그렇게 평가했다고 쓰지 않는다.
- 상태: 재사용·중복 통합.

### 6-2. 협력이 잘되는 조건

- 채택된 비겁·겁재·인성 관련 협력·경쟁 설명을 사용한다.
- 십성으로 특정 사람을 선악으로 분류하지 않는다.
- 상태: 재사용·표현 수정.

### 6-3. 필요한 경계

- 거절 어려움·혼자 해결함·책임 부담 등 실제 약점에 요청·역할·대화 범위를 연결한다.
- 근거 없이 이용당함이나 해로운 관계를 만들지 않는다.
- 상태: 신규 연결.

### 6-4. 도움을 주고받는 방식

- 실제 귀인 표지는 보조로, 협력 조건과 능력은 활동으로 연결한다.
- 본인의 용신·기신 오행으로 타인의 좋고 나쁨을 판정하지 않는다.
- 귀인의 외모·직업·등장일을 만들지 않는다.
- 상태: 수정·신규 연결.

## 10. 7장 가족과 독립

### 7-1. 가까운 사람의 기대

- 채택된 자율성 필요·역할 명확성·거절 어려움을 연결한다.
- 기존 가족사 추정 문장을 이름만 바꿔 재사용하지 않는다.
- 부모 성격·성장환경·간섭의 존재를 추정하지 않는다.
- 상태: 신규 연결.

### 7-2. 책임과 돌봄

- 책임 떠안음·거절 어려움·혼자 해결함이 채택된 경우만 사용한다.
- 실제 돌봄 대상은 사용자가 밝혔을 때만 사용한다.
- 가족 관심 선택은 실제 사건이 아니다.
- 상태: 신규 연결.

### 7-3. 독립성과 도움받기

- 자율성→선택권, 혼자 해결함→도움 요청, 거절 어려움→경계 설정으로 연결한다.
- 소득·주거 정보를 모르면서 경제적 독립 가능성을 판정하지 않는다.
- 상태: 신규 연결.

### 7-4. 먼저 나눌 대화

- 고민을 시간·돈·역할·선택권으로 구분해 관련 판단을 연결한다.
- 질문이 없으면 채택된 핵심 쟁점 하나를 점검한다.
- 실제 갈등이나 가족 속마음을 만들지 않는다.
- 상태: 신규 연결.

## 11. 8장 건강·생활 리듬·회복

### 8-1. 일정이 과해지는 조건

- 채택된 책임 부담·거절 어려움·과도한 확장·완성 지연을 상황에 연결한다.
- 강약·오행으로 체력·장기·질병을 판정하지 않는다.
- 상태: 신규 연결.

### 8-2. 쉬는 시간을 미루는 행동

- 계속 준비함·완성 지연→종료 기준.
- 거절 어려움→추가 요청.
- 혼자 해결함→분담.
- 실제 수면·피로 정보가 없으면 증상을 있다고 말하지 않는다.
- 상태: 신규 연결.

### 8-3. 줄이거나 나눌 일

- 선택한 원인에 대응하는 범위 협의·종료 기준·역할 분담을 제안한다.
- 치료·약·건강식품을 추가하지 않는다.
- 일반 실천 제안과 사주 판단을 구분한다.
- 상태: 신규 연결.

### 8-4. 생활 점검

- 앞서 선택한 행동에 맞는 자기 점검 질문을 제공한다.
- 개인화 근거가 없으면 일반 점검임을 구분한다.
- 상태: 신규 연결.

## 12. 9장 인생의 큰 흐름과 전환점

### 9-1. 현재 대운 구간

- 엔진의 실제 시작·종료와 기준일로 직전·현재·다음을 선택한다.
- 경계 포함 여부와 근사 정책은 엔진 계약을 따른다.
- 자료가 없으면 임의 선택하지 않는다.
- 상태: 계산 재사용·신규 연결.

### 9-2. 구간의 활동 주제

- 대운 천간 십성 계열을 아래 중립 대응으로 설명한다.
  - 비겁: 주도성·동료·경쟁.
  - 식상: 표현·제작·공개.
  - 재성: 수입 활동·거래·비용과 자원 관리.
  - 관성: 역할·책임·평가.
  - 인성: 학습·문서·준비·도움.
- 개인별 길흉 통합 공식이 아니다.
- 재성 대운을 돈 버는 10년, 관성 대운을 합격 구간으로 바꾸지 않는다.
- 상태: 신규 해설 연결.

### 9-3. 앞뒤 구간의 차이

- 같은 필드끼리 비교해 변화와 유지를 설명한다.
- 과거 사건·미래 성취·전성기 순위를 만들지 않는다.
- 상태: 신규 비교.

### 9-4. 현재 상황의 준비

- 활동 주제와 관련된 기존 원국의 강점·약점·사용자 사실을 연결한다.
- 연결 판단이 없으면 활동 설명까지만 한다.
- 상태: 신규 연결.

## 13. 10장 앞으로 12개월

### 10-1. 월별 활동과 조건

- 기준일이 속한 절기 월부터 연속 12개 월운.
- 기존 직업·재물·연애·인간관계 4분야의 월별 직접 근거를 사용한다.
- 실제 겹치는 세운·대운만 보조로 연결한다.
- 긍정·주의 혼합, 긍정만, 주의만, 중립, 자료 부족을 구분한다.
- 건강·가족 월운을 임의 추가하지 않는다.
- 상태: 재사용·범위 연결.

### 10-2. 자세히 볼 활동 구간

- 같은 분야 안에서 기존 긍정 표지 수−주의 표지 수를 편집용으로 사용한다.
- 1 이상 후보 중 상위 최대 3개, 동점은 이른 구간.
- 후보가 없으면 0개를 허용한다.
- 양수여도 반대·주의 근거를 삭제하지 않는다.
- 상태: 기존 선택 재사용·편집 연결.

### 10-3. 조건을 더 점검할 구간

- 같은 분야에서 주의 우세 후보를 기존 방식으로 최대 2개 선택한다.
- 없으면 억지로 채우지 않는다.
- 실패·사고 확정일로 설명하지 않는다.
- 상태: 기존 선택 재사용·편집 연결.

### 10-4. 내 질문과의 관계

- 기간의 활동과 실제 질문의 활동이 맞을 때 원국 판단과 연결한다.
- 지원 자료 정비를 합격일로, 관계 활동을 만남 확정일로 바꾸지 않는다.
- 상태: 신규 연결.

## 14. 의미 태그와 설명 연결

태그는 규칙 작성자가 채택 판단에 붙인다.
생성 문장의 단어를 검색하거나 LLM이 새 판단을 내려 붙이지 않는다.

기존 PATTERN_ABILITY의 실제 내용이 채택된 경우 다음 연결을 사용한다.

- 식신: 꾸준한 결과물 / 익숙한 방식에 머묾
  → 반복 완성과 작은 변형 비교.
- 상관: 문제 발견·개선 / 비판 전달의 마찰
  → 문제·대안·내 역할 구분.
- 정재: 일정·자원 관리 / 작은 오차에 과도하게 매임
  → 계획과 조정 여지.
- 편재: 기회 연결 / 넓히다 마무리하지 못함
  → 작은 시도를 끝낸 뒤 다음 범위 결정.
- 정관: 기준·신뢰 / 기준이 불명확하면 자기 의견을 숨김
  → 기준과 예외에서 자기 판단 설명.
- 편관: 압박 속 판단 / 모든 상황을 긴급하게 다룸
  → 긴급한 것과 일반 과제 구분.
- 정인: 정리·설명 / 준비가 길어짐
  → 설명 자료와 작은 실습 연결.
- 편인: 깊이·독특한 관점 / 완성 전 관심 전환
  → 여러 관점을 결과물로 기록.
- 건록: 스스로 시작 / 도움을 받지 않음
  → 자율 과제와 나눌 역할.
- 월겁: 경쟁 속 추진 / 비교가 과해짐
  → 자신의 과정과 목표 기록.

실제 코드에서 채택되지 않았다면 이 표만으로 능력이나 약점을 생성하지 않는다.

선택 순서:
- 질문에 맞는 태그를 가진 채택 판단.
- 사용자 사실과 모순되는 장면 제외.
- 실제 자유 질문 → 관심 주제 → 관련 상황 → 기본 질문 순서.
- 동률은 버전별 고정 카탈로그 순서와 규칙 ID.
- 같은 원인은 합쳐 설명.
- 발생 조건이 다른 상반 판단은 조건별로 설명.
- 같은 조건에서 직접 충돌하면 혼합으로 남김.

판단은 없지만 고민이 있으면 일반 상황 제안으로 구분한다.
둘 다 없으면 일반 점검을 짧게 제공한다.

## 15. 기간 기준과 충돌

- 첫 유료 분석 시작 시 Asia/Seoul 기준일과 실제 분석 구간을 저장한다.
- 재시도·재열람에서 같은 기준을 사용한다.
- 달력 월과 절기 월을 구분한다.
- 첫 월의 이미 지난 날짜를 미래처럼 설명하지 않는다.
- 엔진의 구간 끝 포함 여부와 시간대 계약을 확인한다.
- 근사 경계에 임의의 오차 범위를 만들지 않는다.

같은 달에 긍정과 주의가 있으면 둘을 함께 설명한다.
원국과 기간의 활동 주제가 다르면 원국 성향과 기간 맥락의 역할을 구분한다.
합과 대립이 함께 있으면 위치와 대상을 구분한다.
동일 인물·기간·필드의 계산값이 충돌하면 해당 연결을 보류한다.

월 중간에 대운·세운 경계가 있으면 표시 구간을 전후로 나눌 수 있다.
월운 직접 근거는 원래 월운에 유지한다.
보조 기간은 실제 겹치는 것만 연결한다.
새 월운이나 근거 ID를 발명하지 않는다.
API로 정확히 연결할 수 없으면 해당 보조 해석을 생략한다.

- twelveStages: 원국·대상 기간과 기준을 보존한 단계 설명.
- contextTwelveStages: 명시한 보조 기간의 단계.
- monthSequence와 일반 rating: 참고 맥락.
- 다른 기간의 근거: 현재 기간의 직접 근거로 사용 금지.

monthSequence·일반 rating을 분야별 점수로 바꾸지 않는다.
이 상품에서 12운성은 단독 사건·길흉 판단 근거로 사용하지 않는다.
분야 간 점수를 합산하거나 비교하지 않는다.

여러 분야에서 같은 월을 선택하면 월은 한 번 표시하고 분야별 이유를 병기한다.
전체 상세 구간은 주목 최대 3개·주의 최대 2개를 편집 목표로 삼되 숫자를 채우지 않는다.

## 16. 고전 자료

앞서 확인한 첫 상품은 고전 요약·궁통보감 120처방을 판단 규칙에 사용하지 않았다.

새 상품에서는:
- 설치된 자료 API와 출처·적용 조건을 확인한다.
- 이미 채택한 판단을 설명하는 관련 자료만 선택적으로 사용한다.
- 120개 전체를 프롬프트에 넣지 않는다.
- 고전 문장으로 미채택 용신이나 새 결론을 LLM이 판단하게 하지 않는다.
- 사용 여부와 이유를 완료 보고에 기록한다.
