# 무진 05. 화면과 필요한 리소스

> 이 문서는 사용자가 2026-11-12에 제공한 무진 상품 설계 명세 원문을 옮긴 것이다. 실제 코드와 다른 점과 구현 결정은 [00_START_HERE.md](00_START_HERE.md)에 기록한다.

## 1. 전체 경험

상품 상세 진입
→ 무진과 대화형 입력
→ 입력 확인
→ 원국 계산
→ 무료 맛보기 작성
→ 책상 위 종이가 확대되며 족자 표시
→ 이용권 또는 결제
→ 쓰는 장면과 함께 유료 장이 점진적으로 완성
→ 전체 족자·후속질문·PDF·보관함.

입력은 대화형이다.
결과는 말풍선 나열이 아니라 긴 HTML 족자 보고서다.

## 2. 장면

사용자가 무진의 책상 맞은편에 앉아 바라보는 구도다.
무진·책상·종이가 같은 공간에 있는 것처럼 유지한다.

상태:
- 기본 대기·입력.
- 자료를 살피는 계산.
- 종이에 쓰는 작성.
- 책상 종이에서 보고서로 확대 전환.
- 보고서 읽기.

계산이 끝났으면 계속 계산 중이라고 표시하지 않는다.
연출을 위해 실제 완료를 인위적으로 늦추지 않는다.
근거 없는 진행률이나 남은 시간을 표시하지 않는다.

## 3. 족자

앱이 정의한 구조화 블록을 사용한다.

- 장 제목.
- 핵심 답.
- 설명 문단.
- 짧은 근거 설명.
- 조건·반대 근거.
- 비교.
- 생활 적용.
- 기간표.
- 점검 항목.

모든 장에 같은 블록을 같은 개수로 강제하지 않는다.
LLM이 임의 HTML·CSS를 생성하게 하지 않는다.
원국·오행·기간표는 실제 구조화 데이터로 렌더링한다.
장식용 운세 확률이나 근거 없는 점수 그래프를 추가하지 않는다.

모바일에서 읽을 수 있는 본문 폭·글자·행간을 먼저 확보한다.
족자 그림 안에 작은 글씨를 끼워 넣지 않는다.
목차 이동과 현재 위치를 제공한다.

## 4. 생성 상태

미구매:
- 무료 내용과 유료 목차·제공 범위를 표시한다.
- 개인 유료 본문을 미리 생성하거나 전송하지 않는다.
- 잠금을 작성 중 스켈레톤으로 표시하지 않는다.

구매 후 생성 중:
- 무료 내용은 계속 읽을 수 있다.
- 완성된 최종 장부터 보여준다.
- 실제 작성 중인 부분만 스켈레톤.
- 실패한 부분은 오류와 재시도.
- 뒤 장이 먼저 완성돼도 목차 순서를 유지한다.
- 사용자가 읽는 위치를 자동으로 맨 아래로 이동시키지 않는다.

재열람:
- 저장 결과를 사용한다.
- 긴 도입·계산 연출을 반복하지 않는다.
- 재생성·재차감하지 않는다.

## 5. 디자인과 접근성

UI 값은 기존 디자인 토큰과 컴포넌트 규격을 사용한다.
일러스트에 금색이 있다는 이유로 UI에 임의 색상 값을 넣지 않는다.
필요한 토큰이 없으면 기존 토큰으로 구현 가능한 방법을 먼저 사용하고 확장 필요를 기록한다.

- 모바일 키보드와 안전 영역.
- 한글 조합 중 Enter 제출 방지.
- 키보드·스크린리더 접근.
- 본문 대비와 긴 표.
- prefers-reduced-motion.
- 영상 실패·자동재생 실패의 정지 화면 대안.
- 무음·인라인 재생.
- 화면 밖·숨긴 탭에서 불필요한 재생 감소.

## 6. 제공된 이미지

실제 첨부 파일을 조사하고 경로·형식·크기를 기록한다.

### A01 캐릭터 설정화

- 권장 이름: mujin-character-sheet
- 역할: 얼굴·복장·체형·장식·표정의 기준.
- 주의: 분리 레이어나 애니메이션 리그가 아니다.

### A02 가로 배너

- 권장 이름: mujin-banner-landscape
- 역할: 상품 배너.
- 주의: 글자가 이미 들어 있으므로 크롭과 중복 제목을 확인한다.

### A03 세로 포스터

- 권장 이름: mujin-poster-portrait
- 역할: 상품 카드·소개.
- 주의: 상담 장면이나 반복 영상이 아니다.

원본 형식을 확인하고 확장자를 맞춘다.
원본을 보존하고 가능한 범위는 화면상 크롭으로 적용한다.

## 7. 추가 리소스 요청

반드시 사용자에게 초기에 다음을 알려라.

### B01 기본 상담 장면

- 사용자 시점에서 무진의 상반신·책상·종이가 보이는 구도.
- PNG/WebP 정지 화면.
- 모바일·데스크톱 안전 크롭 범위.
- 현재 제공된 포스터와 다르므로 별도 제작이 필요하다.

### B02 기본 대기 반복 동작

- B01과 같은 카메라·조명·캐릭터·책상.
- 호흡·눈 깜빡임 등 작은 움직임.
- 무음 WebM/MP4와 정지 포스터.
- 약 4~8초는 제작 출발점이며 고정 요구는 아니다.

### B03 계산·생각 반복 동작

- 같은 구도.
- 자료를 살피거나 생각하는 모습.
- 처음과 끝이 자연스럽게 이어지는 루프.
- 무음 영상과 정지 포스터.

### B04 집필 반복 동작

- 같은 책상·종이 위치.
- 손·붓·종이 접점이 자연스럽게 이어지는 모습.
- 무료·유료 작성에 사용.
- 무음 영상과 정지 포스터.

### B05 프로필·상반신

- 기존 그림의 얼굴 크롭이 충분하면 활용.
- 부족하면 별도 정사각 또는 투명 배경 이미지를 요청.
- 512px 이상을 제작 참고로 삼되 실제 표시 크기에 맞춘다.

### B06 종이 확대·족자 형태

- DOM/CSS/SVG와 기존 토큰으로 구현 가능.
- 별도 전환 영상은 필수가 아니다.
- 종이 위치 기준점은 필요하다.

선택 사항:
- 배경·캐릭터·책상·손·종이 분리 레이어.
- 텍스트 없는 배너·포스터.
- 표정 변형·인장·장식.
- 영상 대신 레이어 애니메이션을 사용할 수 있으며 둘 다 필수로 요구하지 않는다.
- Live2D·외부 영상 서비스·성우·음악은 기본 필수 범위가 아니다.

가로 1920×1080급, 세로 1080×1920급은 원본 제작 출발점으로 제안할 수 있다.
실제 전송 크기와 용량은 화면·대역폭에 맞춰 정한다.

요청서에는 다음을 포함한다.
리소스명 / 확보 상태 / 용도 / 구도 / 크기·비율 / 형식 /
투명 배경 여부 / 반복 조건 / 기준점 / 우선순위 / 임시 대안.

리소스가 없더라도 정지 이미지와 대체 UI로 기능 구현을 계속한다.
임시 리소스를 최종 아트 완료로 보고하지 않는다.

## 8. 보관함·후속질문·PDF

- 상품 ID에 따라 묘묘는 기존 화면, 무진은 족자로 연다.
- 후속질문은 족자 아래나 별도 패널에서 제공한다.
- 기존 횟수·범위·차감 정책을 유지한다.
- 최종 풀이와 실제 근거를 참조한다.
- PDF에는 최종 무진 문장과 실제 표를 넣는다.
- 초안·스켈레톤·결제 버튼·입력 UI는 내보내지 않는다.
- 유료 권한 없는 사람이 유료 본문을 내보낼 수 없게 한다.
