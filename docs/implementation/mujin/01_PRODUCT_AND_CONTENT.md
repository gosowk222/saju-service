# 무진 01. 상품과 내용

> 이 문서는 사용자가 2026-11-12에 제공한 무진 상품 설계 명세 원문을 옮긴 것이다. 실제 코드와 다른 점과 구현 결정은 [00_START_HERE.md](00_START_HERE.md)에 기록한다.

## 1. 상품 정체성

- 캐릭터 이름: 무진 도사
- 상품 이름: 무진의 종합 사주
- 권장 상품 ID: mujin-overview
- 권장 페르소나 ID: mujin
- 기존 식별자 규칙과 충돌하면 동등한 별도 ID로 통일한다.

제공 이미지의 문구:

가로 배너:
- 무진의 종합 사주
- 냉정하게 짚고, 끝까지 봐드립니다
- 현실적 해석과 깊이 있는 흐름 읽기

세로 포스터:
- 무진 종합 사주
- 좋은 말보다 오래 쓸모 있는 답

이미지에 이미 들어간 문구와 HTML 문구가 같은 위치에서 중복되지 않게 한다.
접근 가능한 페이지 제목과 상품 정보는 별도로 제공한다.

새 상품 판매가는 아직 별도 확정되지 않았다.
서버 상품 설정으로 분리한다.
개발 중 기존 테스트 가격을 임시 사용했다면 임시값이라고 기록한다.
기존 990원을 새 상품의 확정 출시 가격으로 간주하지 않는다.

## 2. 무료와 유료 범위

무료로 다음을 제공한다.

- 원국표.
- 원국 분석.
- 오행 분석.
- 원국의 12운성 분석.
- 십성 분석.
- 개인화된 ‘성향과 내면’ 전체.

무료 성향 분석은 그 자체로 완결한다.
핵심 답을 유료에 숨기거나 결론 직전에 문장을 자르지 않는다.

유료로 다음을 제공한다.

- 아래 2~10장.
- 사용자가 궁금해한 내용의 마지막 종합 정리.

권한 확인 전에 유료 초안이나 유료 완성문을 생성하지 않는다.
유료 본문을 브라우저에 보내고 CSS로 숨기는 방식도 사용하지 않는다.

## 3. 확정된 10개 장

장 이름은 목차, 관심 주제 선택지, 진행 상태에서 동일하게 사용한다.

### 1장. 성향과 내면 — 무료

- 중요하게 여기는 방향.
- 중심 성향과 보완되는 면.
- 압박이나 요구에 대한 반응.
- 강점이 손해로 바뀌는 조건.

### 2장. 재능·적성·배우는 방식

- 살릴 수 있는 능력.
- 능력이 드러나는 환경.
- 배우고 연습하는 방법.
- 성과를 막는 조건과 조정 방향.

### 3장. 직업과 사회생활

- 맞는 역할과 업무 환경.
- 조직과 자율 활동의 조건.
- 취업·프리랜서·사업의 비교 기준.
- 현재 상황에서 준비할 것.

### 4장. 재물과 돈 관리

- 돈을 바라보는 방식.
- 돈 관리가 흔들리는 조건.
- 돈과 사람 관계가 얽힐 때의 주의점.
- 자신에게 맞는 관리 방식.

### 5장. 연애와 결혼

- 마음을 표현하는 방식.
- 편안한 관계의 조건.
- 가까워질 때 부딪힐 수 있는 부분.
- 장기 관계에서 합의할 것.

### 6장. 인간관계와 귀인

- 관계에서 맡는 역할.
- 협력이 잘되는 조건.
- 필요한 경계.
- 도움을 주고받는 방식.

### 7장. 가족과 독립

- 가까운 사람의 기대를 받아들이는 방식.
- 책임과 돌봄을 맡을 때의 조건.
- 독립성과 도움받기의 균형.
- 먼저 나눌 대화.

### 8장. 건강·생활 리듬·회복

- 일정이 과해지는 조건.
- 쉬는 시간을 미루는 행동.
- 줄이거나 나눌 일.
- 생활에서 점검할 것.

이 장은 질병·장기·체력·회복 속도의 사주 판정이 아니다.
채택된 행동 경향과 알려진 상황을 바탕으로 생활을 설명한다.

### 9장. 인생의 큰 흐름과 전환점

- 현재 대운 구간.
- 구간의 활동 주제.
- 직전·다음 구간과의 차이.
- 현재 상황에 연결할 준비.

### 10장. 앞으로 12개월

- 실제 분석 기간과 월별 개요.
- 관심 분야의 주목 구간.
- 주의 조건.
- 사용자 질문에 연결한 활동 방향.

### 마지막 정리

- 관련 장의 답을 모아 사용자가 궁금해한 선택과 확인할 조건을 정리한다.
- 새로운 사주 판단을 추가하지 않는다.
- 질문이 없으면 핵심 선택 기준을 간결하게 정리한다.

## 4. 편집 목표 분량

최종 한국어 본문, 공백 포함 글자 수 기준이다.
표의 데이터, 고정 UI, 버튼 문구는 제외한다.

무료:
- 원국 분석: 250~350자.
- 오행 분석: 250~350자.
- 12운성 분석: 200~300자.
- 십성 분석: 300~400자.
- 성향과 내면: 700~1,000자.
- 합계 약 1,700~2,400자.

유료:
- 2장: 650~900자.
- 3장: 1,000~1,300자.
- 4장: 1,000~1,300자.
- 5장: 1,000~1,300자.
- 6장: 650~900자.
- 7장: 650~900자.
- 8장: 550~750자.
- 9장: 850~1,100자.
- 10장: 1,100~1,500자.
- 마지막 질문 정리: 350~550자.
- 합계 약 7,800~10,500자.

전체 약 9,500~12,900자를 초기 편집 목표로 삼는다.

이는 강제 최소 글자 수가 아니다.
분량을 채우기 위해 반복하거나, 범위 밖이라는 이유만으로 자동 재생성하지 않는다.
관심 있는 장에 설명 비중을 더 배정할 수 있다.

## 5. 내용의 깊이

독자가 다음을 이해할 수 있도록 작성한다.

- 무엇을 어떻게 읽었는가.
- 어떤 자료 때문에 그렇게 설명하는가.
- 도움이 되는 조건과 손해가 되는 조건은 무엇인가.
- 현재 상황과 질문에 어떤 의미가 있는가.
- 무엇을 비교하거나 점검할 수 있는가.

모든 장에 같은 소제목·문단 수·농담을 강제하지 않는다.

약점은 다음 흐름으로 구체화한다.
채택된 경향 → 문제가 되는 조건 → 생길 수 있는 비용 → 조정 방법.

생활 장면은 실제 사용자 이력이나 예언으로 쓰지 않는다.
같은 장면과 조언을 여러 장에서 반복하지 않는다.
