## 3. 구현 범위

이번 작업에 포함한다.

- 무진 상품 정의와 무진 도사 페르소나(단일 원천 등록)
- 45개 질문(P01~P05, 1-1~10-4)을 기존 규칙·엔진 계산에 연결하는 무진 작성 계획
- 대화형 입력(지금의 나, 진짜 궁금한 점 포함)과 입력 확인
- 무료(원국표, 기초 분석 4개, 1장)와 유료(2~10장, 마지막 정리)의 장 단위 2-pass 생성, 저장, 재개, 부분 재시도
- 족자 보고서 화면, 상담 장면(임시 정지 그림), 목차와 현재 위치
- 무료 이용권의 무진 사용, 결제 모드 연결(기존 테스트 결제 경로)
- 보관함·후속 질문·PDF 연결
- 호출 단위 토큰 기록과 관리자 화면 조회
- 테스트(단위, PGlite DB, 가짜 서버 브라우저 테스트)와 문서

이번 작업에 포함하지 않는다: 실결제 활성화, 전체 공개 전환, 프로덕션 배포·DB 적용, main/develop 병합, 실제 모델 평가(사용자가 직접 실행), 최종 아트·영상 제작.

## 5. 결정 사항

1. 식별자: 상품 `mujin-overview`, 페르소나 `mujin`, 캐릭터 이름 '무진 도사', 상품 이름 '무진의 종합 사주'.
2. 상품 형식: 상품 정의에 `format`을 둔다. 묘묘는 메신저(기존 정의 내용 변경 없음), 무진은 족자(`scroll`).
3. 가격: 서버 상품 설정의 `priceKrw`에 990원을 **임시값**으로 둔다(`priceStatus: "provisional"`). 기존 테스트 가격과 같은 값을 결제 모드 테스트용으로 쓴 것이며 출시 가격이 아니다.
4. 결제 전 LLM: 묘묘는 지금처럼 결제 전 LLM 호출이 없다. 무진은 무료 범위(기초 분석·1장)를 결제 전에 2-pass로 만든다. 유료 장의 초안·완성문은 권한 확인 뒤에만 만든다(DB 함수가 권한을 다시 확인).
5. 무료 생성 비용 상한: 풀이당 무료 단계 실행 횟수와 회원당 하루 무료 생성 시작 수를 서버 설정으로 제한한다. 값은 임시값이다(미확정 7).
6. 저장: 유료 단계는 기존 `generation_jobs`(권한, 이용권 완료 처리, 점유)를 그대로 쓴다. 무료 단계는 `generation_jobs`를 쓰면 이용권 사용·결제가 막히므로 별도 점유 표를 쓴다. Pass 1 초안은 브라우저가 읽을 수 없는 표에만 둔다.
7. 2-pass 호출 단위: Pass 1은 장 묶음별 스트림 호출이고, 완성된 장마다 검사·저장 뒤 Pass 2 대기열에 넣는다. Pass 2는 장마다 한 번 부르며 동시 실행 수를 설정으로 제한한다. 실패한 장만 다시 한다.
8. 입력 순서: 출생지역을 출생시각보다 먼저 받는다. 시진의 실제 시계 범위가 지역의 시간대·경도로 계산되기 때문이다(명세 순서와 다름). 시각 목록은 엔진 계약대로 자시를 새벽·밤으로 나눈 13개와 '시간 모름'이다.
9. 기준일: 첫 유료 생성이 시작될 때 Asia/Seoul 날짜를 `generation_jobs.reference_date`에 고정하고 재시도·재열람·후속 질문에서 그대로 쓴다.
10. 9장: 출생 시각을 모르면 엔진이 대운을 계산하지 않는다. 이 경우 9장은 근거 부족으로 설명하고 대운을 임의로 고르지 않는다.
11. 규칙: 기존 `first-overview.*` 규칙 결론을 재사용하되, 무진 계획이 명세에서 제외한 분기를 거른다. 새 규칙과 태그표는 `mujin-overview.*`로 두고 모두 `unreviewed`다.
12. 고전 요약·궁통보감: 1차 구현에서는 쓰지 않는다. 요약은 AI 작성·자동검사 상태이고(사람 감수 0건), 궁통보감은 일간·월지 조건만 맞추는 처방이라 이미 채택한 판단을 설명하는 데 필요하지 않다. 사용하려면 장별로 채택 판단과 맞는 자료만 고르는 별도 작업이 필요하다.
13. 모델·추론 강도: 기존 설정을 재사용한다(Pass 1·2는 최초 풀이와 같은 값, 분류·후속 질문은 기존 값). 새 환경 변수와 새 키는 필요 없다.
14. 상담 장면: B01~B04가 없으므로 캐릭터 설정화의 얼굴 크롭과 정지 장면 + 상태 문구로 임시 구현한다. 임시 리소스이며 최종 아트 완료가 아니다.
15. 그림 속 글자: 무진 배너·포스터에는 글자가 이미 있으므로 화면 글자를 그림 위에 겹치지 않고, 화면 읽기용 제목과 상품 정보는 따로 둔다.
16. 이용권: 대상 상품에 무진을 더한다. 캠페인 ID는 그대로라 추가 지급이 없고, 한 장은 두 상품 중 하나에만 쓰인다(기존 회원 단위 잠금).
17. PDF: 묘묘와 같이 권한이 있고 전체 생성이 끝난 풀이만 내보낸다.

## 6. 미확정 사항

1. 출시 가격 (현재 임시 990원).
2. 상담 장면 최종 아트(B01~B04)와 프로필 그림(B05).
3. 실제 모델로 본 무진 문체 품질 (사용자 실행, LIVE_NOT_RUN).
4. 명세가 언급한 21개 문답 예시 원문 (작업 환경에 없음, 평가 문서에 자리만 둠).
5. 무진만 따로 공개·비공개하는 운영 설정 (현재 공개 설정은 모든 상품 공통).
6. 고전 자료 사용 여부.
7. 무료 생성 비용 상한 값.
8. 디자인 토큰 확장(종이 면 색, 중간 크기 serif 제목 등).
9. 실제 카카오 로그인·결제·로컬 Postgres 동시성 검증 (NOT_RUN 예정).
