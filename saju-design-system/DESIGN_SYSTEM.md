# 사주풀이 디자인 시스템 v1.3

> AI 에이전트·개발자용 참고 문서. 값은 `tokens.json` / `tokens.css` / `tailwind.theme.js`가 정본이고, 이 문서는 **어디에 무엇을 쓰는지**를 설명한다. 화면 예시 HTML은 `boards/`에 있다.

## 0. 한 줄 요약

- **서비스**: 사주풀이 웹앱. 20~30대 타깃, 무료 + 유료(유료 비중 높음). 풀이 상품을 포스터 카드로 파는 콘텐츠 커머스 구조.
- **톤**: 보라 주조색 + 라벤더 면 + 인디고 기운 뉴트럴. UI는 깨끗하고 밝게, 드라마(일러스트)는 콘텐츠 포스터가 담당.
- **원칙 3개**: ① 버튼·링크·선택은 전부 `primary-600`, ② 분야색 6종이 곧 오행색·상태색, ③ 텍스트 대비 4.5:1 미만 금지(★ 표시된 값만 글자에 쓴다).

## 2. 색

### 2.1 사용 규칙
- **행동(버튼·링크·선택 탭·활성 아이콘·진행 표시)** → `primary-600 #6E5CE6`. hover `primary-700`. 결제·구매·충전 CTA도 같은 보라(골드 CTA 없음).
- **보조 버튼** → `primary-100` 바탕 + `primary-600` 글자(톤 버튼). 테두리 버튼은 `white` + `gray-200` 테두리 + `gray-900` 글자.
- `primary-500 #8B7CF6`(참고안 원색)은 흰 글자와 3.3:1 → **버튼 금지**, 아이콘·일러스트 배경·그라데이션에만.
- **면**: 카드 `white`, 페이지·섹션 `gray-50`, 칩·비활성·풀이 말풍선 `gray-100`, 선택된 면 `primary-50`.
- **텍스트**: 본문 `gray-900`, 설명 `gray-700`, 보조 `gray-600/500`. `gray-400` 이하는 글자 금지.
- **테두리**: 카드 `gray-200`, 입력 `gray-300`. 카드에 그림자 없음. 그림자는 바텀시트·툴팁(`shadow-float`)에만.
- **포커스**: `primary-600` 2px + `primary-100` 3px 외곽 링.
- **그라데이션**: `primary-400 → 600`, 135°. 오늘의 운세 배너·히어로 CTA에만. 카드 면에는 쓰지 않는다.
- **밤 히어로**: `primary-900 #2B2457` 바탕 + 흰 글자. 랜딩 인트로, 포스터 플레이스홀더 톤.

### 2.2 분야색 = 오행 틴트 = 상태색
같은 계열의 `-600`(또는 gold `-700`)은 글자, `-50`은 바탕, `-400`은 범례 점·아이콘 원색.

| 분야 | 오행 | 상태 | 글자 | 바탕 | 원색 |
|---|---|---|---|---|---|
| 연애 | — | danger · 할인·인기 배지 · 흉(凶) | `rose-600 #C2366B` | `rose-50 #FDE8EF` | `rose-400 #F28BB3` |
| 재물 | 土 | warning · 유료 배지 · 코인 · 대길 | `gold-700 #9A6700` | `gold-50 #FFF4D6` | `gold-400 #F2B544` |
| 직업 | 水 | — | `blue-600 #2B63C6` | `blue-50 #E3EEFC` | `blue-400 #6FA8F0` |
| 궁합 | 木 | success · 무료 배지 · 길(吉) | `green-600 #257F60` | `green-50 #E1F5EE` | `green-400 #5CC0A0` |
| 인생 | 火 | — | `orange-600 #B55A12` | `orange-50 #FFEBD9` | `orange-400 #F39A4A` |
| 성격 | 金 | neutral · 완료 배지 | `gray-500 #716D8E` | `gray-100 #ECEAF5` | `gray-400 #A9A6C0` |
| 오늘 · 궁합 타일 | — | info | `primary-600` | `primary-50` | `primary-500` |

- 명식 표의 천간·지지 칸은 오행 틴트 바탕 + 오행 글자색 + Serif 한자. 일간(日干)은 2px 아웃라인으로 강조.
- 색만으로 구분하지 않는다: 오행 글자(木火土金水)·길흉 한자를 항상 병기.

### 2.3 고정값(토큰 아님)
- 카카오 로그인: `#FEE500` 바탕 + `#191600` 글자, radius 12. 다른 곳에 재사용 금지.
- 포스터 위: 하단 스크림 `rgba(0,0,0,.72) → 0 (60%)` + 흰 제목 + 72% 흰 부제. 스크림 농도를 72% 아래로 내리지 않는다.
- 일러스트·포스터 자체는 팔레트 제약을 받지 않는다(콘텐츠 자산). 단 톤은 밤 인디고 계열을 권장.

## 3. 타이포그래피
- `--font-sans` Noto Sans KR(Pretendard 교체 가능, 토큰 불변): UI·본문·숫자. 굵기 400/500/600, **700은 가격·숫자 강조에만**.
- `--font-serif` Noto Serif KR: display, heading-1, 천간·지지 한자, 포스터 위 제목. 본문에는 쓰지 않는다.
- 스케일: display 44/52 · h1 32/40 · h2 24/32 · h3 20/28 · title 18/26 · body-lg 17/26 · body 15/22 · label 14/20 · caption 12/16 · caption-sm 11/14(배지·탭 라벨만, **10px 금지**) · hanja 28 Serif 500 +0.02em.
- 가격: Sans 700 + `tabular-nums`, 정가 취소선은 `gray-500` 400. 할인율은 rose.
- 한자 뒤에는 한글 음을 괄호로: 甲木(갑목). 한 줄 28~40자, 본문 최대 너비 640px.
- 캐주얼 서체(Jua·Orbit 등) 금지 — 돈을 내는 서비스라 신뢰감 우선.

## 4. 간격 · 라운드 · 모션 · 레이아웃
- **간격** 4px 격자: 2·4·8·12·16·20·24·32·40·52·120. 카드 안쪽 16, 포스터 그리드 간격 12, 섹션 사이 40, 화면 좌우 16(모바일)/20.
- **라운드**: sm 8(배지) · md 12(포스터 이미지·한자 칸·소셜 버튼) · lg 16(카드·입력) · pill 22(44px 버튼·칩) · xl 24(바텀시트·히어로) · full.
- **모션**: fast 150ms(버튼·링크·입력) · base 200ms(모달·탭·카드 펼침) · slow 300ms(바텀시트·결과 드러남·캐러셀 스냅). easing `cubic-bezier(0.4,0,0.2,1)`, 퇴장 `(0.4,0,1,1)`. 마키·무한 핑 금지. `prefers-reduced-motion`에서 0ms.
- **레이아웃**: 모바일 우선(375 기준). 데스크톱(768+)에서도 **중앙 단일 컬럼 max-width 600px**, 바깥 `gray-50`. 사이드 내비 없음. 포스터 그리드 `repeat(auto-fill, minmax(150px, 1fr))`.
- **하단 탭** 4개 고정: 홈 · 탐색 · 보관함 · 마이. 높이 56 + 안전영역. 활성 = `gray-900` + 600 굵기(색만으로 구분 X).
- 터치 타깃 44px 이상. 아이콘 Lucide 2px 스트로크(탭 22, 인라인 18, 타일 24). 이모지 금지.

## 7. 금지 목록
- `primary-500`·`gray-400`·`-400` 원색을 작은 글자에 쓰기
- 골드 버튼(결제는 보라), 빨강 별도 토큰(danger는 rose)
- 카드에 그림자, 그라데이션 면, 이모지 아이콘, 10px 글자
- 마키·무한 반복 애니메이션, 300ms 초과 전환
- 사이드 내비·960px 본문(데스크톱도 600px 중앙 컬럼)
- 캐릭터·외부 서비스명·타사 일러스트 사용. 포스터 자리는 자체 일러스트로 채운다.

## 8. 보드 파일 안내
`boards/*.html`은 디자인 캔버스에서 내보낸 화면 소스다. 인라인 스타일로 모든 값이 적혀 있어 그대로 열어 보거나 마크업을 참고할 수 있다. Google Fonts 링크가 들어 있어 온라인이면 Noto Sans/Serif KR로 렌더링된다. `[일러스트]` 라벨 박스는 이미지 자리다.
